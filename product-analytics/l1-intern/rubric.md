# Rubric — L1 Analytics Intern

Assessed on **fundamentals, curiosity and honesty about uncertainty**. Expect them to
write correct basic SQL and to ask what the question really means.

## Competencies and the bar

| Competency | Below level (1–2) | At level (3) | Above level (4) |
| --- | --- | --- | --- |
| **SQL** | Cannot write a grouped aggregate | Joins, groups and filters correctly; understands NULL and DISTINCT | Writes readable CTEs and sanity-checks their own output |
| **Statistics** | Confuses correlation and causation | Explains p-values and medians correctly; spots obvious bias | Identifies Simpson's paradox or selection bias unprompted |
| **Metrics** | Reads any number as fact | Defines retention and conversion precisely; asks for the denominator | Proposes the right metric for a question they were not given |
| **Communication** | Leads with method, buries the answer | Answer first, caveat included, chart fits the question | Adjusts the message for the audience and states what they cannot know |
| **Curiosity** | Executes the request literally | Asks what the question is for | Reframes a badly posed question into a useful one |

## Must have

* Working basic SQL — joins, group by, aggregates — written live, not just claimed.
* Correct definitions of average vs. median, correlation vs. causation.
* Willingness to say "I don't know" and reason out loud.

## Nice to have

* Python or R.
* A BI tool.
* A personal analysis project of any kind.

## Red flags

* States a conclusion from data with no caveat at all.
* Cannot debug their own query when told the number is wrong.
* Uses statistical vocabulary without being able to explain it.

## First 90 days if hired

Own one dashboard, answer scoped questions for one team, and produce one written
analysis that leads to a decision.
