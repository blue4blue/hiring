# Communication and Tools

- Stating the answer before the method
- Choosing a chart type that matches the question
- Axis, scale and labelling honesty
- Writing up an analysis: question, method, result, caveat, recommendation
- Spreadsheet fluency: pivot tables, lookups, basic modelling
- BI tool basics (Looker, Metabase, Tableau, Power BI — any one)
- Python or R basics: pandas, plotting
- Version control basics for analysis code
- Documenting assumptions
- Asking clarifying questions before starting work
