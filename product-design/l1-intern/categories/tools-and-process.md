# Tools and Process

- Figma fundamentals: frames, auto-layout, constraints, components, variants
- Naming, structure and file hygiene others can navigate
- Using an existing design system rather than reinventing it
- Prototyping: clickable flows for testing an idea
- Version history and safe iteration
- Handoff basics: specs, tokens, redlines, what engineers actually need
- Design QA: checking the built result against the design
- Basic understanding of HTML/CSS concepts (box model, flex, responsive)
- Documenting a decision so it survives you
- Time management on a defined brief
