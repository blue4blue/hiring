# Data and Metrics Basics

* What is the difference between DAU and MAU? What does the ratio between them tell you?
* Our signup conversion is 12%. Is that good?
    * What would you need to know to answer that?
* Average session length went up 20% last week. Is that good news?
    * What could make that number rise for a bad reason?
* What is the difference between correlation and causation? Give an example from a product.
* When would you use a median instead of an average?
* We launched a feature and revenue went up. What would you check before claiming credit?
* Given a table of `users(id, signup_date, country)` and `orders(id, user_id, amount, created_at)`, how would you count orders per country last month?
    * (SQL is a bonus at this level; the logic is the requirement.)
* A dashboard shows 0 sign-ups yesterday. What are your first three hypotheses?

## Follow-ups to test depth

* "What is the denominator?" — the single most useful metric question.
* "Over what time window, and compared to what?"
