# Interview Loop

A reference loop for product roles. Adjust the number of rounds by level: junior roles
need fewer, leadership roles need more stakeholder exposure. Never add a round without
naming the specific signal it is there to collect.

## Standard loop by level

| Level | Rounds | Typical duration |
| --- | --- | --- |
| L1 Intern | Screen → Fundamentals → Team fit | 1 week |
| L2 Junior | Screen → Fundamentals → Case → Team fit | 1–2 weeks |
| L3 Mid | Screen → Craft deep-dive → Case/exercise → Cross-functional → Hiring manager | 2 weeks |
| L4 Senior | Screen → Craft deep-dive → Case/exercise → Cross-functional → Hiring manager → Leadership | 2–3 weeks |
| L5 Lead | As L4 + peer-leadership panel + mentoring/coaching signal | 3 weeks |
| L6 Head | Screen → Strategy deep-dive → Org & hiring → Business case → Exec panel → Board/founder | 3–5 weeks |
| L7 C-level | Founder/CEO → Strategy & vision → Org design → Board/investor exposure → Peer execs → References | 4–8 weeks |

## What each round is for

* **Recruiter screen** — motivation, compensation range, notice period, visa/location, obvious dealbreakers.
* **Craft deep-dive** — the discipline-specific skill. Use the `questions/` files for the target level.
* **Case / take-home / exercise** — how they think when the problem is ambiguous. Time-boxed, and paid if it exceeds 2 hours.
* **Cross-functional interview** — run by engineering, design, data, or sales, depending on the role. Tests collaboration as reported by the people who will actually work with them.
* **Hiring manager** — scope, ownership, ways of working, growth trajectory.
* **Leadership / exec panel** — strategic judgement, executive communication, values.
* **References** — always for L5+, ideally two managers and one peer or direct report.

## Rules

* One signal per round. Two interviewers testing the same competency is a wasted round for the candidate and for you.
* Every interviewer writes their scorecard **before** reading anyone else's.
* Candidates get the same core questions at the same level, so comparisons mean something.
* Tell the candidate the loop up front, including how many rounds and what each covers.
* Cap the loop. If you cannot decide after the planned rounds, the answer is no — an extra round rarely rescues a genuine doubt.

## Take-home and case guidance

* Use a problem close to real work, but never a problem you actually need solved.
* Time-box explicitly and state that you will read only what fits inside the box.
* Score the reasoning, not the polish. A rough artefact with sharp thinking beats a beautiful deck with none.
* Always follow a take-home with a live discussion — it is the only way to know they did the work themselves.
